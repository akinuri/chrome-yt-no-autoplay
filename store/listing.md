# Listing

## Title
YouTube No Autoplay

## Summary
Stop videos from autoplaying.

## Description
Videos on a page start playing on their own. This extension pauses them, so a video only plays when you click it or press play.

On page load the video stays paused and shows its poster (thumbnail) where the site provides one. After that, play and pause work as usual.

## Single purpose
Prevent YouTube videos from playing until the user starts them.

## Permission justification
None; the extension requests no `permissions`.

## Host permission justification
Needed to pause autoplaying videos on YouTube pages (www.youtube.com). The script runs only on this domain.
